# Restaurant Management System

A full-stack Restaurant Management System developed using ASP.NET Core Web API and React (Vite).

## Features

- User Authentication
- Customer Dashboard
- Admin Dashboard
- Food Ordering
- Cart & Checkout
- Table Reservation
- Reservation Management
- Inventory Management
- Order Tracking
- Customer Profile
- Change Password

## Technologies Used

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Router
